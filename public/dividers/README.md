# Theme divider assets

Ten original transparent PNG horizontal rules generated with OpenAI image generation for Adventure Drafter. The editor displays the centered ornament in a thin 36px strip. A theme-following rule resolves to the current palette; a specifically selected design keeps its image when the palette changes. Source images are retained at their generated resolution.

Generation prompt recipe, with the motif and ink substituted from the table:

> Use case: logo-brand. Asset type: transparent raster horizontal section divider for Adventure Drafter, a tabletop adventure document editor. Create ONE extremely thin elegant horizontal rule: [motif]. Uniform ink color [ink]. Landscape canvas. The complete rule spans 90% of the width and at most 6% of the height, centered. Long delicate hairlines taper at the ends around a tiny ornament, crisp ink. Actual alpha transparency. No paper, shading, texture, glow, shadow, text, labels, or border. A narrow, understated print-book strip.

Full style presets map to their corresponding palette, with Modern quest using Ocean blue. Custom ink changes retain the preset's divider unless a named palette matches.
